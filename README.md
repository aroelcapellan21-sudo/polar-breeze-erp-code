# Polar Breeze ERP — Código

Este repositorio contiene el código de implementación del ERP Polar Breeze.

La arquitectura, reglas de negocio y modelo de datos que este código debe respetar viven en el repositorio de documentación [`polar-breeze-erp`](https://github.com/aroelcapellan21-sudo/polar-breeze-erp) (privado, cuenta `aroelcapellan21-sudo`) — la Constitución Arquitectónica del proyecto. Ningún código de este repositorio puede contradecir lo ya aprobado ahí.

## Regla de oro

Ninguna entidad, evento o regla se implementa aquí sin existir primero, documentada y aprobada, en `polar-breeze-erp`. Si el código y la documentación entran en conflicto, la documentación tiene autoridad — se corrige el código, o se abre una discusión para cambiar la documentación primero, nunca se resuelve solo en código.
